# Пушистый переполох

Это моя игра, написанная на Python с использованием библиотеки Pygame.

## Как запустить
1. Сначала нужно установить pygame: `pip install pygame`
2. Потом просто запускаете главный файл: `python main.py`

## Суть игры
* В главном меню нажмите ПРОБЕЛ для старта.
* Управление самое простое - стрелочки ВЛЕВО и ВПРАВО.
* Ваша задача - управлять платформой, отбивать светлячков (мячики) и ловить падающих зверьков. 
* Осторожно, не ловите молнии от тучек, они отнимают жизни!
* **Враги:** Остерегайтесь злых птичек (которые сбрасывают камни) и огромного босса-орла на 4-м уровне!
