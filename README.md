# 🐾 Пушистый переполох

Игра на Python + Pygame в жанре «арканоид с элементами аркады».
Управляйте платформой, спасайте зверьков и сражайтесь с боссами!

## Установка и запуск

```bash
pip install pygame
python main.py
```

## Управление

| Клавиша | Действие |
|---|---|
| ← / → | Двигать платформу |
| ПРОБЕЛ | Начать игру (из меню) |
| P | Пауза / продолжить |
| ESC | Вернуться в меню (после Game Over) |

## Геймплей

- Отбивайте мяч платформой, чтобы **выбивать зверьков** из рядов
- **Ловите падающих зверьков** платформой — каждый даёт +20 очков
- 🟡 **Золотой зверёк** даёт дополнительную жизнь вместо очков
- Поймайте 3 зверька подряд → **КОМБО! +50 очков**
- Пропущенный зверёк снимает −15 очков

## Уровни

| Уровень | Особенность |
|---|---|
| 1 | Классика — только зверьки |
| 2 | Ветер и облака с молниями |
| 3 | Птицы-враги с быстрыми зверьками |
| 4 | **Босс-ястреб** (6 HP) |
| 5+ | Два мяча одновременно |
| 7 | **Мега-босс** (12 HP) |

## Архитектура (MVC)

```
main.py         — точка входа, игровой цикл
models.py       — вся игровая логика (Model)
  ├─ ScoreManager     — сохранение/загрузка очков (SRP)
  ├─ LevelManager     — конфигурация уровней (SRP)
  └─ CollisionHandler — обнаружение коллизий (SRP)
views.py        — отрисовка (View)
controllers.py  — обработка ввода (Controller)
constants.py    — все игровые константы
tests.py        — юнит-тесты (18 тестов)
assets/         — спрайты и музыка
```

## Запуск тестов

```bash
python -m unittest tests.py -v
```
